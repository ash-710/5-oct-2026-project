# In-Memory Database
The project contains a basic implementation of an in-memory database.

---
### Implementation details
Per online instructions,
- No AI tool was used to generate code or make architecture decisions.
- As a style guide was not specified, code is uploaded without any style.
- Rigorous testing has not been performed as unit tests were considered beyond the scope.

Per offline instructions,
- No features more advanced than pointers and arrays were used.
- `goto` (an advanced feature) was not used causing the cleanup code to be repeated.
- One large function is present as breaking it apart would have been an advanced feature.
- Custom data types would have allowed for easier handling but were not permitted.
